# Недельное меню PDF

Приватный плагин-навык с повторно используемой инструкцией для составления PDF-рецептов на неделю. Используй навык `weekly-meal-recipes-pdf`.

В `assets/reference-menu-13-19-oct-2026.pdf` хранится сжатая копия утверждённого пользователем PDF с 25-страничной структурой. Встроенные фотографии служат иллюстрацией внешнего вида и не являются доказательством соответствия ингредиентам. Не копируй из эталона старые даты, калорийность или состав блюд без независимой проверки.

Этот навыковый плагин не содержит фонового сервера и не гарантирует автоматическое создание PDF при запуске scheduled tasks: это зависит от инструментов, доступных в момент запуска.
